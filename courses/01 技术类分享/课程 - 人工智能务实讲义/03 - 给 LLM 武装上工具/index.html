给 LLM 配上外挂的努力

因为 LLM 是一个有各种限制，也没有接触任何现实世界信息媒介的文科大脑，因此大部分的产品，都是围绕这样一个大脑 + 一堆外挂构建出来的。

1.0 版本: ChatBot 形态

2023-2025 主流

ChatGPT，Qwen，豆包的初级版本都是这样。

本质： LLM + 具体的外挂（联网，计算，Excel，Word，Pdf 等）

2.0 版本：Agent + 外挂形态

2025-2026 主流

例如 DeepResearch，PPT 制作工具等。

本质： 预定好的外挂们，用 Agent 的自评估循环，实现更复杂任务的完成。

3.0 版本：Coworker 形态

极其早期

OpenClaw（小龙虾 🦞）代表的 Coworker 形态，可自己生产外挂，因此显得更万能。

局限： 极高的复杂度和极低的 Token 效率。
