Markdown 语法指南

Markdown 是 AI 输出内容的标准格式。掌握这些基础语法，不仅能帮你更好地阅读 AI 回复，还能提升你编写提示词（Prompt）的专业度。

基础文本格式

  • 加粗 (Bold)

    **文本内容**
    示例：文本内容

  • 斜体 (Italic)

    *文本内容*
    示例：文本内容

  • 删除线 (Strikethrough)

    ~~文本内容~~
    示例：文本内容

使用 # 数量代表标题等级

二级标题示例

三级标题示例

代码与引用

行内代码

在句中使用 `code`

多行代码块

```python
def hello():
    print("Hello AI")
```

提示：在三个反引号后写上语言名称（如 python, html）可开启语法高亮。

引用内容

使用 > 符号可以创建引用块，常用于摘录 AI 之前给出的建议。

💡 进阶技巧

  • • 分割线： 使用三个连字符 --- 可以产生一条水平线。
  • • 转义符号： 如果想显示 # 而不是标题，在前面加反斜杠：\#
  • • 强制换行： 在行尾输入两个空格再回车。
