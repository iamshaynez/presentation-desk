# Infographic 内容


我在准备培训材料，目标是让学员了解 Agentic Coding 工具基本概念和用法，行业可见的优点和缺陷，最终目的是带回企业中构建企业内的最佳实践。

标题：Agentic Coding 工具的自主效应

- 因为 Agentic Coding 工具的自主效应，让 LLM + Coding Skills(Tools) 一定程度上自主决策和规划，从而可以独立自动的完成复杂编码任务。
- 横向膨胀：很多酷炫的 Demo 展示，Agentic Coding 可以一条提示词，生成复杂度极高功能繁复的完整产品。LLM 的本质是，限制越少，发挥越好，这类秀肌肉的 Demo 能体现是的 Agentic Coding 工具的自主效应，上下文管理能力，但不是严肃使用的场景所追求的。
- 纵向膨胀：严肃使用的场景，往往意味着更多的规范规则和约束，更复杂的既有架构需要遵循。因此，Agentic Coding 在单一功能上的深度和健壮度方面发力膨胀，才是我们追求的。
- Vibe Coding 真正有效使用，需要真正懂编程和程序的底层原理，并把精力大量花在约束上。
- 举例子，最佳实践。
