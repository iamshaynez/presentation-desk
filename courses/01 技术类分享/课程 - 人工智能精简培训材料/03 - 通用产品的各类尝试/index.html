联网查询
Web Search

赋予模型“眼睛”，连接实时互联网世界。

  • 解决事实性错误（幻觉）
  • 获取最新新闻与数据
  • 查询天气、股票等实时信息

计算模块
Code Interpreter

赋予模型“左脑”，通过代码执行精确计算。

  • 弥补数学计算能力的缺陷
  • 执行 Python 代码进行统计
  • 绘制图表和数据可视化

特殊格式工具
File Parsers

打破文本限制，处理专业文档格式。

  • 读取 PDF、Word 长文档
  • 解析 Excel 表格数据
  • 提取扫描件文字 (OCR)

其他技能
Expanded Skills

连接外部应用，实现自动化操作。

  • AI 绘图 (DALL-E / Midjourney)
  • 发送邮件与日程管理
  • 数据库查询与 API 调用
