主题：Agentic Coding 的最佳实践

- 核心前提：

Vibe Coding 的含义是“Vibe Coding，直译过来其实就是“氛围编程”或者叫“沉浸式编程”。 只看结果，不看过程的黑盒编程。” 显然，严肃的编程领域（核心原因是目前模型的能力，上下文边界无法处理真实世界软件工程的复杂度）是不能靠 Vibe 的，需要更系统化的工程实践。

- 实践部分：
    - 提示词：
        - 提示词准确性，结构化（标准提示词工程的技巧）
        - 工具会提供：全公司，全用户，项目级等方便分层管理，项目级需要保存在项目内
    - 上下文管理：
        - 上下文管理是指在 Agentic Coding 中，如何管理和维护上下文信息，以便在不同的任务和交互中保持一致的状态。
        - 上下文管理可以包括：
            - 理解上下文的大小，限制，召回率对控制的影响
            - 单次任务的上下文管理，清空
            - 通过引用等方式，让最重要的上下文信进入单次交互的主流程（规范，关联代码，指引等）
    - 编码实践：
        - 一次做一个功能，一次 git commit
        - 如果复杂，效果差，则不如回退重来，否则越涂越黑（因为逐渐丢失上下文）
        - 感知模型能力边界，控制指令和上下文大小，避免超出边界
