Coding Agent 预装标准系统调用接口 (System Interface)

Active v2.0 Protocol

文件系统操作 (File System)

fs.read_file Input: path

读取指定路径的文件完整内容。通常支持行号标记以辅助后续编辑。

fs.write_file Input: path, content

创建新文件或完全覆盖现有文件内容。适用于初始化或重写。

fs.apply_diff Input: path, search, replace

智能编辑工具。通过匹配独特的代码块（Search Block）并将其替换为新代码（Replace Block）来修改文件，避免上下文丢失。

fs.list_dir Input: path, recursive?

获取目录结构树。帮助 Agent 理解项目架构和文件位置。

终端执行 (Terminal Execution)

shell.execute Input: command

在系统 Shell (Bash/Zsh) 中执行命令。用于安装依赖、运行测试、启动服务器或 git 操作。

Stream Output User Approval
bg.run_server Input: command

以后台模式运行长时间进程（如 npm start），并允许 Agent 随时检查日志或终止进程。

代码导航与分析 (Analysis)

code.search / grep Input: regex, path

在代码库中进行正则表达式搜索。用于定位函数定义、变量引用或特定字符串。

lsp.get_definitions Input: file, symbol

利用语言服务器协议 (LSP) 获取类、函数或变量的类型定义和签名信息。

浏览器与视觉 (Browser/Vision)

browser.launch 启动无头或有头浏览器环境 (Puppeteer/Playwright)。
browser.screenshot 捕获当前页面截图，通过 Vision Model 分析 UI 布局错误。
browser.click 模拟用户点击坐标或 DOM 元素，进行端到端测试。
console.get_logs 获取浏览器控制台报错日志。
