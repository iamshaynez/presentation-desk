Code Agent 是什么？

不仅仅是代码补全。它是一个具备感知、规划、行动能力的智能体，
通过编排专门的技能（Skills）来解决复杂的工程问题。

Core Agent

中央控制器 / 编排者

核心职责

负责理解模糊的需求，拆解任务步骤，维护上下文记忆，并决定在何时调用哪个具体的 SKILL。它是系统的"大脑"。
