Coding Agent 交互架构

从用户意图到机器执行的 Prompt 流向全景

USER PROMPT

用户主体意图。作为最高指令，直接指挥 Agent 的核心逻辑，定义本次工作的最终目标。

INPUT: "帮我写一个贪吃蛇游戏..."

USER SKILL PROMPT

用户自定义工具。定义特定的逻辑或规则，作为 Agent 的扩展技能在细分任务中被调用。

DEF: "当遇到数据库操作时，使用..."
Coding Agent Container

Agent Core System Prompt

Agent 的大脑。包含内置的 System Prompt，负责理解 User Prompt 的意图，规划任务，并根据需要调用下方的 Skills。

注入: USER PROMPT (作为当前 Goal)
Orchestration (任务编排)
plan = analyze(user_prompt)
tools = [file_gen, web_search, user_skill]
execute(plan, tools)
