AI 编程新范式

Agentic Coding 实践流派全景

从传统的测试驱动到新兴的 "Vibe" 驱动，探索 AI 辅助编程时代的多样化工程实践与方法论融合。

01

TDD 测试驱动开发

遵循 Red-Green-Refactor 循环。

观点： TDD 问“构建得对吗？”，Vibe 问“值得构建吗？”。可利用 Vibe 快速原型，TDD 兜底质量。

02

SDD 规范驱动开发

规范（PRD/文档）是单一事实来源。

观点： 结构化极强，要求前置工作充分。AI 可基于详尽规范生成精准代码。

03

BDD + Gherkin 行为驱动开发

使用 Given-When-Then 自然语言描述行为。

共振： Gherkin 天然契合 Prompt 工程。实现了 Vibe Coding 追求的代码、测试、需求“三位一体”。

04

DDD 领域驱动设计

统一语言与边界上下文。明确 Constrained Improvisation。

策略： 人类定义核心领域与不变性，AI 负责外围实现的广度与速度。

05

ATDD 验收测试驱动开发

“三个朋友”（业务、开发、测试）协作定义验收条件。

特点： 强调开发前明确标准。与 BDD 类似，但更侧重测试规范格式。

06

PDD 提示驱动开发

将需求分解为结构化提示序列。

区别： 比 Vibe 更严肃的方法论。PDD 针对生产/可维护性，Vibe 针对原型/探索。

07

Vibe Testing 体验感测试

关注应用“感觉”如何（流畅、快、安全）。

新颖性： AI 自动生成海量用例探索用户体验。与 BDD 互补（功能正确 vs 体验满意）。

08

Property-Based 基于性质的测试

定义不变性质，而非具体用例。

用法： AI 负责寻找破坏性质的边界反例。常与 SDD 结合定义 "Then Property"。

09

Event-Driven 事件驱动开发

以事件为中心的架构设计与建模。

场景： Event Modeling 用于前期理解，AI 辅助实现 Event Sourcing。

10

Raw Vibe Coding 原始/纯粹流派

最小人工审查，完全拥抱 AI 迭代。

双刃剑： 极致的速度与创意，适用于黑客马拉松。风险是高技术债。

关键流派对比分析

流派 核心专注 人工介入度 质量保证机制 最佳场景
Vibe Coding 速度/创意 最小 运行时反馈 原型、黑客马拉松
TDD 正确性、设计 高 前置测试 生产代码、关键系统
SDD 规范清晰度 中-高 规范驱动生成 AI 友好的需求定义
BDD 业务对齐 中 行为验证 跨职能团队协作
DDD 架构、业务逻辑 高 结构约束 复杂领域建模
PDD 可维护性 高 方法论流程 生产应用、规模化
Constrained Improvisation 创新与约束平衡 中-高 两层验证 快速开发 + 复杂业务
