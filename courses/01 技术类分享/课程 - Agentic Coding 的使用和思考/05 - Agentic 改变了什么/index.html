Integration Depth

LLM

单点 (Point)

基础的对话与生成能力。AI 作为工具存在，提供离散的知识支持。

Agent

平面 (Plane)

任务流的串联。AI 开始具备规划与工具使用能力，在平面维度扩展价值。

Agentic OS

立体 (Volume)

以 Openclaw 为例。深度整合到价值流中，形成操作系统级别的闭环生态，彻底改变生产方式。

为什么 Coding 率先被改变？

Coding Workspace 天然解决了 上下文一体化 与 验证闭环 的问题

上下文

Context

工作所需的所有知识：

  • 通用编程知识
  • 专业领域逻辑
  • 企业内部规则与架构

可执行

Executability

明确的方法论与边界：

代码即指令。如同 Agent Prompt，编程具有天然的结构化指令集，动作边界清晰，执行路径明确。

可验证

Verifiability

有明确的预期结果：

  • 代码跑通/报错 (0/1)
  • 测试用例通过率
  • 高置信度的反馈循环
对比： 其他领域的“上下文”和“可验证性”更难定义，但正在被攻克。
