主流开发框架生态

LangGraph

Stateful Graph

基于图论的编排。允许循环、条件跳转，适合构建复杂的、有状态的生产级 Agent。

AutoGen

Multi-Agent Conversation

微软出品。将 Agent 视为对话者，通过群聊模式自动协作，代码生成能力强。

CrewAI

Role-Based

角色扮演模式。定义 Role、Goal、Task，模拟人类团队的层级化工作流。

MCP Protocol

Model Context Protocol

Anthropic 提出的开放标准。 旨在标准化 LLM 与数据源（如 Linear, GitHub, Google Drive）的连接方式，打破数据孤岛。
